# Voorbeeld van de uitvoer

Dit is wat de radar maakt van [de voorbeeldkaart](../techniekkaart.json): drie
verzonnen apps met bewust oude onderdelen. De uitvoer is van 27 november 2026.
De meldingen zijn echt; draai je het voorbeeld zelf, dan zie je de stand van
dat moment.

| Bestand | Wat het is |
| --- | --- |
| [ochtendmail.txt](ochtendmail.txt) | De mail als platte tekst. De opgemaakte versie staat als afbeelding in de [README](../../README.md) |
| [rapport.md](rapport.md) | Het volledige rapport, ook met de minder dringende meldingen. In GitHub staat dit bij elke run onder Summary |
| [instructie-klantportaal.md](instructie-klantportaal.md) | De instructie voor de developer van één app |

Zelf draaien:

```bash
npm run voorbeeld
```
