# De radar laten instellen door Claude Code

**Waar:** Claude Code, in de map van de radar.

**Wanneer:** Je hebt de repository binnengehaald met git clone en wilt dat Claude de rest met je doorloopt.

```text
Ik heb de kwetsbaarheden-radar van Pilex binnengehaald in deze map. Zet hem voor me op.

Volg de handleiding in deze repository (CLAUDE.md). Werk in drie fasen en vraag mijn akkoord voordat je iets aanmaakt of verstuurt:
1. Lokaal testen: eerst het voorbeeld, dan mijn eigen apps op de techniekkaart, dan een droge run.
2. De mail koppelen en één proefmail versturen.
3. Uitrollen, zodat de radar elke ochtend vanzelf draait.

Vertel me eerst wat je van mij nodig hebt en vraag daarna één ding tegelijk. Ik ben geen programmeur.

Wachtwoorden en tokens typ ik zelf in het bestand .env. Vraag er niet om en lees dat bestand niet.
```
