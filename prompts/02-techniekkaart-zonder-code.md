# De techniekkaart als je de code niet bij de hand hebt

**Waar:** Claude, in een gewoon gesprek.

**Wanneer:** De app is gebouwd in Lovable, Bolt of door een bureau, en je weet niet waar je moet beginnen.

```text
Ik heb een app in gebruik die ik niet zelf heb geprogrammeerd. Ik wil weten uit welke techniek hij bestaat, zodat ik kan laten controleren of er beveiligingslekken in zitten. Help me dat stap voor stap uit te zoeken. Ik ben geen programmeur.

Stel me eerst deze vragen, één voor één, en wacht steeds op mijn antwoord:
1. Hoe heet de app en wat doen mensen ermee?
2. Waarmee is hij gebouwd: Lovable, Bolt, Replit, v0, Claude, of door een bureau of developer?
3. Staat de code in GitHub, en heb ik daar zelf toegang toe?
4. Waar draait de app: bij welke hostingpartij?
5. Welke gegevens staan erin: namen, e-mailadressen, klantgegevens, facturen, of niets gevoeligs?

Leg daarna in gewone taal uit, voor mijn situatie:
- Waar ik het bestand vind waarin alle onderdelen met hun versie staan (het lockfile), en hoe het heet bij mijn bouwtool.
- Hoe ik de code in GitHub krijg als die daar nog niet staat, met de knoppen waar ik op moet klikken. Zeg het erbij als je de knoppen niet zeker weet.
- Wat ik aan mijn bureau of developer moet vragen als ik er zelf niet bij kan. Schrijf die vraag voor me uit als een kort bericht dat ik kan doorsturen.

Sluit af met een lijst van wat ik nu heb en wat er nog ontbreekt om de app op de techniekkaart te zetten. Verzin geen versienummers en geen onderdelen: wat we niet weten, zetten we op de lijst met open punten.
```
