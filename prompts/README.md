# Prompts

Acht prompts voor Claude, bij de stappen van de radar. Kopieer de tekst uit het
grijze blok en vul in wat tussen vierkante haken staat.

| Nr | Prompt | Waar | Wanneer |
| --- | --- | --- | --- |
| 1 | [De techniekkaart van één app, uit de code](01-techniekkaart-uit-de-code.md) | Claude Code | Je hebt de code en wilt weten waar de app van gemaakt is |
| 2 | [De techniekkaart als je de code niet bij de hand hebt](02-techniekkaart-zonder-code.md) | Claude | De app is gebouwd met een bouwtool of door een bureau |
| 3 | [De radar laten installeren door Claude Code](03-radar-installeren.md) | Claude Code | Je wilt hulp bij het opzetten |
| 4 | [Een melding laten uitleggen](04-melding-uitleggen.md) | Claude | De mail noemt een lek en je wilt weten wat het betekent |
| 5 | [De update laten uitvoeren](05-update-uitvoeren.md) | Claude Code | Je wilt de instructie uit de mail zelf laten uitvoeren |
| 6 | [Van de eerste mail naar een plan](06-nulmeting-opruimen.md) | Claude | De eerste run geeft een lange lijst |
| 7 | [Het bericht aan je developer of IT-partner](07-bericht-aan-developer.md) | Claude | Je zet de update uit bij iemand anders |
| 8 | [De ochtendcheck als geplande taak in Claude](08-ochtendcheck-in-claude.md) | Claude Cowork | Je wilt vandaag beginnen, nog zonder de radar |

Prompt 8 is een lichte variant voor wie nog geen GitHub heeft. Claude leest de
bronnen dan zelf en controleert alleen de hoofdonderdelen die je in de prompt
zet. De radar controleert elk onderdeel uit het lockfile, met vaste regels.

De uitleg bij elke prompt staat in de gids:
[pilex.ai/kwetsbaarheden-radar](https://www.pilex.ai/kwetsbaarheden-radar).
